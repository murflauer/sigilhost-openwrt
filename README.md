## 📦 Списки

Готовые `.lst`-списки для выборочной маршрутизации:

* 🌐 домены
* 🛰️ IP-подсети
* 🔀 отдельные сервисы

Каждый сервис лежит в своей папке: `AI`, `Anime`, `Denuvo`, `Discord`, `Roblox`, `Spotify`, `Telegram`, `TikTok`.

> Файлы, имя которых оканчивается на `ip.lst` (например `discordip.lst`), содержат IP-подсети.
> Остальные `.lst` содержат домены.

### 📡 Telegram: подсети обновляются сами

Клиент Telegram подключается к серверам **напрямую по IP**, поэтому одних доменов недостаточно.
Файл `Telegram/telegramip.lst` **автоматически** синхронизируется с официальным списком
[core.telegram.org/resources/cidr.txt](https://core.telegram.org/resources/cidr.txt)
(IPv4 и IPv6, проверка каждый час). Вручную его править не нужно: правки перезапишутся.

> Если Telegram не запускается, убедитесь, что подключены **оба** списка: домены и подсети.
> Подробнее в разделе «Решение проблем».

## 🧩 Forkop: наши списки в «Встроенных наборах правил»

Для **Forkop** списки можно добавить прямо в выпадающий список
**Секция → Условия → Встроенные наборы правил**.
Они появятся с пометкой `sigil_*`: `sigil_ai`, `sigil_roblox`, `sigil_discord`, `sigil_telegram` и так далее.
Сразу видно, какие наборы ваши.

Выполните по SSH:

```sh
wget -qO- https://raw.githubusercontent.com/murflauer/sigilhost-openwrt/main/menu.sh | sh
```

После этого **обновите страницу LuCI жёстким обновлением (Ctrl+Shift+R)**
и выберите нужный набор в списке. Наборы `sigil_*` стоят в самом начале
выпадающего списка

> Если пунктов `sigil_*` нет, браузер показывает старую версию интерфейса.
> См. раздел «Решение проблем» ниже.

Что важно знать:

* Работает **только в Forkop**. Для Podkop используйте быструю установку ниже.
* Каждый набор `sigil_*` собирается из **доменов и IP-подсетей** сервиса одновременно
  (`*.lst` и `*ip.lst` попадают в один `.srs`), отдельно подключать подсети не нужно.
* Скрипт изменяет файлы самого Forkop. Резервные копии лежат рядом (`*.sigil-orig`).
* После **обновления Forkop** изменения пропадают. Просто запустите команду ещё раз.
* Повторный запуск безопасен: дубликаты не создаются.
* Наборы собираются автоматически из `.lst` в `.srs`

## ⚡ Быстрая установка (Podkop и Forkop)

Одна команда по SSH добавит все списки как внешние ссылки.
Ссылки искать и вставлять вручную не нужно.

**Все сервисы сразу:**

```sh
wget -qO- https://raw.githubusercontent.com/murflauer/sigilhost-openwrt/main/install.sh | sh
```

**В конкретную секцию** (по умолчанию `main`):

```sh
wget -qO- https://raw.githubusercontent.com/murflauer/sigilhost-openwrt/main/install.sh | SEC=имя_секции sh
```

Скрипт сам:

* определяет, что установлено: Podkop или Forkop
* находит все списки во всех папках репозитория
* добавляет домены и IP-подсети в нужные внешние списки секции
* перезапускает сервис

Секция должна уже существовать. Повторный запуск безопасен: дубликаты не создаются.
Запустите скрипт ещё раз, если хотите получить новые списки, добавленные в репозиторий.

## 🛠️ Ручное подключение

Списки можно подключить напрямую по ссылке.
Ничего скачивать на компьютер не нужно.

Откройте:

**Podkop / Forkop → нужная секция → Условия → Списки доменов и IP**

Нажмите **Добавить список** и вставьте нужную ссылку в формате GitHub **RAW**, например:

```
https://raw.githubusercontent.com/murflauer/sigilhost-openwrt/main/Discord/discordip.lst
```

После добавления сохраните настройки и примените конфигурацию.

> 💡 Если сервис состоит и из доменов, и из IP-подсетей, подключайте оба списка.
> Для Telegram это обязательно.

## 🔄 Обновление

### На стороне репозитория (автоматически)

* Списки хранятся на GitHub и обновляются **без изменения ссылки**.
* Подсети Telegram подтягиваются с официального источника **каждый час**.
* Наборы `sigil_*` пересобираются при каждом изменении `.lst` и раз в час.
  В релиз `srs` загружаются **только новые и изменённые** файлы,
  а наборы, для которых больше нет списков, удаляются.
* При изменении любого `.lst` автоматически выпускается новый релиз с описанием изменений.

### На стороне роутера (по вашему выбору)

Выберите, как часто роутер должен обновлять списки сам:

```sh
wget -qO- https://raw.githubusercontent.com/murflauer/sigilhost-openwrt/main/autoupdate.sh | sh
```

Скрипт задаст вопрос:

```
1) Раз в день
2) Раз в неделю (понедельник)
3) Не обновлять (отключить)
```

Обновление выполняется в **03:00 по Москве**, когда нагрузка минимальна.
Время автоматически пересчитывается в часовой пояс вашего роутера.

Без вопроса:

```sh
wget -qO- https://raw.githubusercontent.com/murflauer/sigilhost-openwrt/main/autoupdate.sh | sh -s daily    # раз в день
wget -qO- https://raw.githubusercontent.com/murflauer/sigilhost-openwrt/main/autoupdate.sh | sh -s weekly   # раз в неделю
wget -qO- https://raw.githubusercontent.com/murflauer/sigilhost-openwrt/main/autoupdate.sh | sh -s off      # отключить
```

Что делает скрипт: создаёт `/usr/bin/sigil-update` и запись в cron.
Обновление перезапускает Forkop/Podkop, чтобы он заново подтянул актуальные наборы.
Проверить вручную и посмотреть результат:

```sh
sigil-update
logread | grep sigil
```

## 🩺 Решение проблем

**Telegram не запускается**

Клиенту нужны не только домены, но и IP-подсети дата-центров.

* подключите оба списка: `Telegram/telegram*.lst` (домены) и `Telegram/telegramip.lst` (подсети),
  либо используйте набор `sigil_telegram` (в нём есть и то, и другое);
* если у провайдера есть IPv6, а правила для него не применяются, трафик пойдёт мимо туннеля:
  оставьте IPv6-подсети в списке или отключите IPv6 на LAN;
* для звонков нужен UDP: проверьте, что он не блокируется правилами.

**Пунктов `sigil_*` нет в выпадающем списке (Forkop)**

Выход из аккаунта и вход заново не помогают: LuCI хранит файлы интерфейса
в кеше браузера. Сделайте одно из двух:

* нажмите **Ctrl+Shift+R** на странице Forkop (жёсткое обновление);
* либо откройте DevTools (**F12**) → вкладка **Network** → включите
  **Disable cache** → обновите страницу.

Можно также открыть LuCI в приватном окне браузера.

Если не помогло, проверьте, что патч применился:

```sh
grep -c sigil_ /www/luci-static/resources/view/forkop/main.js
```

Ответ `0` значит, что патч не применён. Запустите команду из раздела Forkop ещё раз
и пришлите её вывод в **Issue**.

**Скрипт пишет «пропуск sigil_…: нет …srs»**

Набор ещё не собран. Откройте **Actions → Build SRS → Run workflow**
и дождитесь зелёной галочки.

**После обновления Forkop пунктов `sigil_*` больше нет**

Обновление пакета заменило файлы Forkop. Запустите `menu.sh` ещё раз.

**Автообновление не срабатывает**

* проверьте, что запись есть: `grep sigil-autoupdate /etc/crontabs/root`;
* убедитесь, что cron запущен: `/etc/init.d/cron status`;
* запустите `sigil-update` вручную и посмотрите `logread | grep sigil`.
