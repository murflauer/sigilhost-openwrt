## 📦 Списки

Готовые `.lst`-списки для выборочной маршрутизации:

* 🌐 домены
* 🛰️ IP-подсети
* 🔀 отдельные сервисы

---

## 🚀 Как подключить

Списки можно подключить напрямую по ссылке.
Ничего скачивать на компьютер не нужно.

### Podkop / Forkop

Откройте:

**Podkop / Forkop → нужная секция → Внешние списки доменов**

Нажмите **Добавить список** и вставьте нужную ссылку формате github **RAW**

После добавления списка сохраните настройки и примените конфигурацию.

> 💡 Если сервис состоит и из доменов, и из IP-подсетей, рекомендуется подключать оба списка.

---

## 🔄 Обновление

Списки хранятся на GitHub и могут обновляться без изменения ссылки.

Ваш роутер просто скачивает актуальную версию списка по той же ссылке.
